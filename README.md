# ⚡ Orb Collector 3000

> A fast-paced 3D orb collection game built with Three.js

![Game](https://img.shields.io/badge/Three.js-r160-000?logo=three.js)

**Play now:** https://jin2005-issues.github.io/orb-collector-3000/

---

## Controls

| Key | Action |
|-----|--------|
| WASD / Arrow Keys | Move |
| Mouse Drag | Orbit camera |
| Scroll | Zoom |
| Left Click | Dash (1.5s cooldown) |

## Features

- 🌟 Colorful orb collection with particle explosions
- 👾 Wave-based enemy AI
- 💥 Screen shake, damage numbers, kill feed
- 🔊 Web Audio sound effects
- 🎨 Bloom, vignette, color grading post-processing

## Tech

Three.js r160 · Vanilla JS · ES Modules
